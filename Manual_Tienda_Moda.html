2. Tecnologías Utilizadas

La plataforma está desarrollada con un enfoque robusto y escalable:

🐘 PHP 8.x

Lenguaje principal con arquitectura MVC (Modelo-Vista-Controlador).

🐬 MySQL 8.x

Motor de base de datos relacional con integridad referencial.

🌐 HTML5/CSS/JS

Frontend interactivo y responsive con diseño "Boutique".

📦 Composer

Gestión de dependencias (FPDF, PHP Barcode Generator).

3. Funcionalidades del Sistema

💰 Módulo de Ventas (Punto de Venta)

Interfaz rápida para creación de tickets: buscador de productos, carrito dinámico, impresión de comprobante, asignación de cliente y anulación de ventas.

📦 Inventario y Productos Multi-Variante

Gestión completa con atributos de Talla y Color (variantes). Control de stock mínimo, generación de códigos de barras universales (CODE128).

⚙️ Sucursales, Caja y Compras

Soporte Multi-Sucursal para control independiente. Sesiones de caja diarias con registro de gastos. Compras a proveedores conectadas al stock.

📊 Reportes y Dashboard

Reportes analíticos de ventas por fechas, Kardex de entradas/salidas de productos, métricas principales.

4. Instalación (Equipo Nuevo) y Uso CMD

Requisitos

  • Laragon Full (Apache, MySQL 8+, PHP 8+)
  • Composer instalado

Pasos desde CMD

# 1. Instalar dependencias
cd C:\laragon\www\tienda_moda
composer install

# 2. Base de datos (MySQL)
mysql -u root -p < bk_basededatos.sql

# 3. Arrancar servidores
cd C:\laragon\bin
laragon.exe start

Acceso Web: http://localhost/tienda_moda

6. Hosting Recomendado y Despliegue

Veredicto de Hosting

Se recomienda Hostinger Premium por su velocidad optimizada para PHP/MySQL, certificados SSL gratuitos ilimitados, su panel en español (hPanel) altamente intuitivo, y los mejores precios del mercado de hosting compartido. Ideal para boutiques y PyMEs.

Paso a Paso (Despliegue)

  1. Comprime todo el proyecto (C:\laragon\www\tienda_moda) en un archivo ZIP.
  2. En Hostinger, crea una Base de Datos en la sección "Gestión de bases de datos".
  3. Importa bk_basededatos.sql en phpMyAdmin.
  4. En el "Administrador de archivos" de Hostinger, sube y extrae el ZIP dentro de public_html.
  5. Abre app/core/Database.php y edita las credenciales con el nuevo usuario y password de la BD de Hostinger.
  6. Edita public/index.php y deja la variable $folder = '';
  7. Activa el Certificado SSL y el sistema estará en línea.
